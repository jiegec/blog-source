计算过程

Yf 是 full-range 的亮度 Y（USB 实际输出的是 limited：Y = 16 + (219/255)·Yf）； ΔR = R−Yf、ΔB = B−Yf 是色差，等于 1.5748·(Cr−128) 和 1.8556·(Cb−128)，也就是把标准 Cb/Cr 去掉 128 偏移、去掉归一化后回到 R/B 单位。 limited range 的裁剪等价于 Yf∈[0,255]、ΔR∈[−200.8,200.8]、ΔB∈[−236.6,236.6]， 所以高饱和颜色会“顶住”而不再线性增长。这里只建模 luma / chroma 两步，不含 4:2:0 色度二次采样与 8-bit 量化的残差（实测约 ±1~4）。
