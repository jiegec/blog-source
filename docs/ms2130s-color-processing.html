MS2130S luma / chroma processing 可视化

MateBook Pro 通过 HDMI 输出 RGB（4K30 RGB，0x3c47=0x00，0xf130=0x10）。 芯片内部把 RGB 分解成 Y/ΔR/ΔB，先过 luma（0xfc90 / 0xfc91）， 再过 chroma（0xfc92 / 0xfc93），最后重建 RGB。 下面用实测数据验证这条链路。

MateBook Pro RGB → 实测验证

实测值来自博客合并表：MateBook Pro RGB 的 9 个灰阶 + 12 个彩色输入， 四种 0xfc8e/0xfc8f 组合。验证使用默认寄存器 0xfc90=0xF5、0xfc91=0x94、0xfc92=0xB4、0xfc93=0x00。

纵轴是 ΔR（Cr），横轴是 ΔB（Cb）。gain 只改变向量长度（饱和度），hue 改变向量方向（色相）。 灰色（ΔR=ΔB=0）在原点，gain/hue 都不移动它。虚线是 limited-range 裁剪边界 ΔR∈[−200.8, 200.8]、ΔB∈[−236.6, 236.6]。
